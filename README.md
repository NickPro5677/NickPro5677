## In English

I'm a Computer Engineering student at UNEG in Puerto Ordaz, Venezuela. I build most of my projects on an Android phone with Termux: Python and FastAPI APIs, local network monitoring tools, Bash automation and small games. I'm interested in defensive security, AI and games, and I'm open to internships and freelance work.

- **fnf-agent** — browser rhythm game you, a bot or an external AI can play (WebSocket relay in Python for Termux). [Demo](https://nickpro5677.github.io/fnf-agent/)
- **maquina-de-turing** — 2D/3D Turing machine simulator with exercises, dark mode and offline support (v1.2.0 on Pages). [Demo](https://nickpro5677.github.io/maquina-de-turing/)
- **wifi-zero** — home network monitoring from a Pi or PC, with a phone dashboard (Python standard library, tests).
- Live demos: [FNF-Agent](https://nickpro5677.github.io/fnf-agent/) · [Turing machine](https://nickpro5677.github.io/maquina-de-turing/) · [Calculator](https://nickpro5677.github.io/Calculadora-digital/) · [Password generator](https://nickpro5677.github.io/Generador-de-contrase-as/) · [To-Do List](https://nickpro5677.github.io/To-Do-List/)
