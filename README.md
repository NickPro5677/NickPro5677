## 🚀 Proyectos destacados

### [fnf-agent](https://github.com/NickPro5677/fnf-agent)
Plataforma local para jugar y evaluar agentes sobre *Friday Night Funkin'*: motor de juego en Python (Pillow), agentes enchufables en Node que hablan con el motor por socket, visor web con HUD y pad táctil, y servidor MCP opcional para clientes externos.
`Python` · `Node.js` · `MCP` · `Termux`

### [wifi-zero](https://github.com/NickPro5677/wifi-zero)
Vigilancia de **mi propia red local** desde Android sin root: inventario de dispositivos (ARP + fabricante), análisis de redes Wi‑Fi, motor de reglas anti‑intrusión, puntuación de riesgo por host y panel web con login y eventos en vivo. 100 % biblioteca estándar de Python, con tests y documentación de arquitectura, seguridad y ética.
`Python` · `SQLite` · `Seguridad` · `Termux`

### [api-ejercicios](https://github.com/NickPro5677/api-ejercicios)
API REST con un banco de ejercicios de programación para repasar antes de exámenes: CRUD de categorías y ejercicios, filtros y paginación, registro de intentos y estadísticas de progreso. Incluye un shell interactivo en español y tests con pytest.
`Python` · `FastAPI` · `SQLite` · `Pydantic`

### [termux-scripts](https://github.com/NickPro5677/termux-scripts)
Utilidades en Bash para Android/Termux: monitor y registro de batería, organizador de archivos del teléfono (con modo simulación por defecto) e inventario del almacenamiento.
`Bash` · `Termux`

### [Plataformas1](https://github.com/NickPro5677/Plataformas1)
Mi primer juego de plataformas en GameMaker: movimiento con teclado, salto, gravedad, colisiones píxel a píxel y reaparición al caer fuera de la sala. Código GML comentado en español.
`GameMaker` · `GML` · `Videojuegos`
