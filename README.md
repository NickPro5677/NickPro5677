## 🚀 Proyectos destacados

### [fnf-agent](https://github.com/NickPro5677/fnf-agent)
Juego de ritmo en el navegador al estilo de *Friday Night Funkin'*: puedes jugar tú, un bot o una IA externa por WebSocket. Funciona en el teléfono y sin internet. El relay en Python (Termux) sirve para conectar agentes; el motor viejo quedó en `legacy/`.
[▶ Probar](https://nickpro5677.github.io/fnf-agent/) · [Release v4.1.0](https://github.com/NickPro5677/fnf-agent/releases/tag/v4.1.0)
`JavaScript` · `Python` · `WebSocket` · `Termux`

### [maquina-de-turing](https://github.com/NickPro5677/maquina-de-turing)
Simulador de máquina de Turing en 2D y 3D: ejemplos, ejercicios, modo oscuro, español e inglés. Funciona sin internet, en el teléfono y en proyector.
[▶ Probar](https://nickpro5677.github.io/maquina-de-turing/) · [Release v1.1.0](https://github.com/NickPro5677/maquina-de-turing/releases/tag/v1.1.0)
`JavaScript` · `Three.js` · `PWA`

### [wifi-zero](https://github.com/NickPro5677/wifi-zero)
Vigilancia de **mi propia red local** desde Android sin root: inventario de dispositivos (ARP + fabricante), análisis de redes Wi‑Fi, motor de reglas anti‑intrusión, puntuación de riesgo por host y panel web con login y eventos en vivo. 100 % biblioteca estándar de Python, con tests y documentación de arquitectura, seguridad y ética.
`Python` · `SQLite` · `Seguridad` · `Termux`

### [api-ejercicios](https://github.com/NickPro5677/api-ejercicios)
API REST con un banco de ejercicios de programación para repasar antes de exámenes: CRUD de categorías y ejercicios, filtros y paginación, registro de intentos y estadísticas de progreso. Incluye un shell interactivo en español y tests con pytest.
`Python` · `FastAPI` · `SQLite` · `Pydantic`

### [termux-scripts](https://github.com/NickPro5677/termux-scripts)
Utilidades en Bash para Android/Termux: monitor y registro de batería, organizador de archivos del teléfono (con modo simulación por defecto) e inventario del almacenamiento.
`Bash` · `Termux`

### [Plataformas1](https://github.com/NickPro5677/Plataformas1)
Mi primer juego de plataformas en GameMaker: movimiento con teclado, salto, gravedad, colisiones píxel a píxel y reaparición al caer fuera de la sala. Código GML comentado en español.
`GameMaker` · `GML` · `Videojuegos`

## 🇬🇧 In English

I'm a Computer Engineering student at UNEG in Puerto Ordaz, Venezuela. I build most of my projects on an Android phone with Termux: Python and FastAPI APIs, local network monitoring tools, Bash automation and small games in GameMaker. I'm interested in defensive security, AI and backend development, and I'm open to internships and freelance work.

- **fnf-agent** – browser rhythm game you, a bot or an external AI can play (WebSocket relay in Python for Termux). [Demo](https://nickpro5677.github.io/fnf-agent/)
- **maquina-de-turing** – 2D/3D Turing machine simulator with exercises, dark mode and offline support. [Demo](https://nickpro5677.github.io/maquina-de-turing/)
- **wifi-zero** – home network monitoring from Android without root (Python standard library, tests, web dashboard).
- **api-ejercicios** – REST API for practicing programming exercises (FastAPI + SQLite, 40 tests).
- Live demos: [FNF-Agent](https://nickpro5677.github.io/fnf-agent/) · [Turing machine](https://nickpro5677.github.io/maquina-de-turing/) · [Calculator](https://nickpro5677.github.io/Calculadora-digital/) · [Password generator](https://nickpro5677.github.io/Generador-de-contrase-as/) · [To-Do List](https://nickpro5677.github.io/To-Do-List/)
